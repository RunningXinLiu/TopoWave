# TopoWave 操作手册

1. 在项目根目录启动 `python workbench.py`。模板库的“三层地形与水洞”收录六个带本地结果的模板。选择“查看已算结果”即可载入，选择“载入并编辑输入”可从模板建立自己的模型。
2. 在“模型与观测”中编辑各层厚度、Vp、Vs 和密度，设置地表控制点、炮点和接收阵列。内部区域可设置几何与填充物。已有结果对应原始输入，修改参数后可另存场景。
3. 在计算设置中调整 dt、传播时间和单元尺寸。自动填入的数值是当前模型的候选值。配置本机求解器后，可先生成实际网格、查看网格 QC，再计算新的一炮。
4. 在“波场快照”播放、暂停或拖动时间，区分固体速度与流体压力。单炮页保留所有接收道和完整记录，节点可切换 Vx/Vz；水平直光纤可选择有限标距 DAS 应变率。
5. 在单炮页打开面波分析，检查面波窗、道范围、频带和扫描速度。PS 和 FH 均可用，空间等权为默认，Hann 为可选项。台阵中心的理论参考可选择阶数。对于起伏地形，该曲线对应局部一维柱；对于有限洞体，它对应无洞背景。
6. 要看水洞效应，在随包水洞结果的单炮页打开“有洞／无洞对比”。同一地形的配对记录、窗和频散图共用炮检参数。

其他研究模板提供可编辑输入，预计算结果的可用性以本地文件为准。六份随包结果的检查范围见[案例说明](../qc/layered_terrain/README_zh.md)。
