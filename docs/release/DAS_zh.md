# DAS：当前计算的是什么

在「单炮记录」顶部，观测量选「DAS 应变率（水平直光纤）」，旁边填写标距L（m）。也能提前在「分析设置…」保存该选择。悬停观测量、标距标签或数字输入可查看说明，点击「DAS说明」可持续阅读。

SPECFEM2D保存水平粒子速度Vx（m/s），当前观测算子为：

`strain_rate(x,t) = [Vx(x+L/2,t) - Vx(x-L/2,t)] / L`

这是水平直光纤、均匀标距权重下的平均轴向应变率，单位s⁻¹。它等于标距内∂Vx/∂x的空间平均；不使用Vz、不另求时间导数。节点速度来自已算正演，切换或改变L只做接收后处理，不需要重新正演，也不包含光学仪器响应或应变传递耦合。

通道中心沿用原接收位置。两端必须落在已有Vx接收点，不插值、不缩短边缘标距。均匀道距Δx时，此中心选择要求L=2nΔx。例如当前平地300m模板：151道、2m道距，L=8m时左右端点距中心各4m，首尾各去掉2个中心，输出147道。道距仍2m，不能把标距8m当成道距8m。

较长标距会平均短波长信号；平面波空间因子为2i·sin(kx L/2)/L，相对局部空间导数为sinc(kx L/2)。因此可能衰减甚至出现零点，不能靠增大L保证能量图更干净。倾斜入射影响沿光纤的kx和Vx。

当前仅支持水平平地直光纤，起伏地表上的弯曲光缆需要沿弧长的切向投影与积分，尚未接入。山丘模板选择DAS会明确提示未应用。当前没有应变（无量纲）选项；若要应变需对应位移/积分处理及其独立验证。

DAS的PS/FH使用实际派生DAS时间窗，不能把它与Vz能量幅值直接等同。FH在有限标距DAS上是对照算子；理论参考位置仍是完整原始阵列中心，不随DAS裁边移动。
